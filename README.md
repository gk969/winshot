# WinShot

Windows 屏幕截图工具,MFC C++ / Win32,x64。界面与交互按仓库里那 28 张参考图逐张实现。

## 构建

需要 VS2022(v143 工具集)+ Windows SDK 10.0.26100.0,静态 MFC。

```
msbuild winshot.vcxproj /p:Configuration=Debug /p:Platform=x64
```

产物 `x64\Debug\winshot.exe`。命令行构建要先 `call vcvars64.bat`。

## 使用

启动后没有窗口,只在任务栏右下角放一个托盘图标。

- **Ctrl+Shift+A** 呼出截图,托盘菜单里的“截图”同样可以。热键被别的程序占用时会弹气泡提示、菜单项去掉快捷键标注,不会静默失败。菜单里还有“开机启动”开关。
- 呼出瞬间整个虚拟桌面被冻结成一张位图,所以正在播放的视频会被静态截下来。
- 默认选中全屏;左键拖动新建选区,拖选区内部移动,拖 8 个手柄缩放;方向键微调 1px(按住 Shift 10px)。
- 选区下方是工具栏:矩形 / 椭圆 / 箭头 / 画笔 / 马赛克 / 文字 / 序号 ‖ 撤销 / 长截图 / OCR / 钉在桌面 / 屏幕录制(本期未实现,置灰)/ 保存 ‖ ✕ / ✓。选中某个工具后其下方再出属性条(线宽、色板、字号、模糊度滑块)。
- **✓** 复制到剪贴板(同时写 `CF_DIB` 和 `CF_BITMAP`),**Ctrl+S** 存 PNG,**钉在桌面**把选区贴回桌面且截图退出后仍然存活,**OCR** 用系统自带的 `Windows.Media.Ocr` 识别选区文字。
- **Esc** 或 ✕ 退出截图。

## 长截图

点长截图后选区内变成实时桌面(一个"洞"),滚动目标窗口,程序每 150ms 抓一帧,用已累积图末尾的重叠带做行签名匹配,把新出现的行拼到下面。停止滚动后点 **编辑** 带拼接结果回到编辑器,点 **保存** 直接出 PNG。

- 拼接结果可以高于屏幕,选区会跟着长到屏幕外,此时工具栏自动翻到选区上方。
- 滚轮能落到洞下面的窗口,靠的是窗口区域本身(不用 layered 窗口):不属于窗口的区域既透出桌面也透入鼠标。覆盖层另外把 `WM_MOUSEWHEEL` 转发给 `WindowFromPoint` 找到的窗口,因为 Windows 是按焦点而不是按光标位置投递滚轮的。
- 上限 30000 px 高、256 MB 像素缓冲。画面跳变过大时停止自动拼接并提示,不会瞎猜偏移。
- 吸顶表头、固定页脚这类内容会被重复拼进去,需要事后手动裁剪。

## 已知限制

- **DRM 保护的内容**(部分播放器、宽屏保护的视频)用 `BitBlt` 抓回来是纯黑,这是系统行为,无法绕过。
- 屏幕录制未实现,按钮按参考图位置画出但不可点。
- 多显示器混合 DPI:跨屏的覆盖层只拿到主屏 DPI。因为全部几何都用物理像素,覆盖层本身每屏都对;只有内联文字编辑框在异 DPI 屏上字号会略偏。

## 测试

- `tests\stitcher_test.cpp` —— 拼接算法的单元测试,独立编译:
  `cl /EHsc /std:c++20 /W4 /Fe:obj\stitcher_test.exe /Fo:obj\ tests\stitcher_test.cpp src\longshot\Stitcher.cpp`
- `tools\*.ps1` —— 每个阶段一个验收脚本,自己启动 winshot、驱动鼠标键盘、抓屏断言像素。`stage2_test`(选区与桌面逐像素对齐)、`stage3_tb`/`stage3_flip`(工具栏槽位与翻边)、`stage4_test`(标注+撤销+输出)、`stage5_test`/`stage5b_test`/`stage5c_test`(箭头画笔序号 / 文字与 IME / 马赛克)、`stage6_test`(放大镜)、`stage7_test`(钉图 + OCR)、`stage8_test`(长截图拼接)。
